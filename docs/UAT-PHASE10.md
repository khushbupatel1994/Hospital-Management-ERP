# Hospital UAT Matrix

- Reception: patient registration, search, appointment creation
- Doctor: patient history access, notes, permissions
- Laboratory: order, status, result access
- Pharmacy: stock, dispensing, low-stock alert
- Billing: invoice, payment, report
- Admin: users, roles, audit logs
- IT: health check, backup, restore drill
- Security: MFA, failed-login handling, session revocation

Record each case as PASS/FAIL, evidence, defect ID, retest result.

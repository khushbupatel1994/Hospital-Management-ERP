# Privacy & Security Readiness Checklist

This is an engineering checklist, not legal advice or a compliance certificate.

- [ ] Identify categories of personal/health data processed.
- [ ] Map data flows between client, API, database, backups and AI provider.
- [ ] Define purpose and lawful basis/consent workflow where applicable.
- [ ] Define retention and deletion rules.
- [ ] Define role-based access and least privilege.
- [ ] Encrypt data in transit and protect data at rest.
- [ ] Maintain security/audit logs with controlled access.
- [ ] Document incident response and escalation.
- [ ] Document backup and disaster recovery procedures.
- [ ] Review every third-party processor/vendor.
- [ ] Review AI data handling and minimum-necessary disclosure.
- [ ] Conduct security testing and remediate findings.
- [ ] Obtain hospital legal/privacy/security approval before production.

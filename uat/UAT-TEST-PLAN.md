# Hospital UAT Plan

## Reception
- Register patient
- Search patient
- Book appointment
- Cancel/reschedule appointment

## Doctor
- Open authorized patient record
- Review history
- Review lab results
- Verify role restrictions

## Laboratory
- Create test
- Update status
- Verify pending-test dashboard

## Pharmacy / Inventory
- Issue medicine
- Update stock
- Verify low-stock alert
- Verify expiry alert

## Billing
- Create invoice
- Verify totals
- Verify role restrictions

## Administration
- Create user
- Change role
- Disable user
- Review audit log
- Test MFA for privileged account

## Recovery
- Create backup
- Restore into isolated test database
- Verify record counts and integrity

Every test must record: Test ID, Date, Tester, Result, Evidence, Defect ID, Retest Result.

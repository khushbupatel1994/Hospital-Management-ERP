# Hospital Administrator Quick Start

## Daily
- Review system health.
- Review failed logins and security alerts.
- Confirm backup status.
- Review user access changes.
- Review critical operational alerts.

## Weekly
- Verify backup restore evidence.
- Review inactive accounts.
- Review audit logs for unusual activity.
- Review pending software/security updates.

## Access Control
Grant the minimum permissions required for each job role. Remove access promptly when a user's role changes or employment ends.

# Hospital Demo Script

## 20–30 Minute Demonstration

1. **Login & Security** — demonstrate role-based access.
2. **Dashboard** — show patient, appointment, laboratory, pharmacy, billing and operational indicators.
3. **Patient Workflow** — register a demo patient and open the patient profile.
4. **Appointment** — create and review an appointment.
5. **Doctor/OPD** — demonstrate a normal clinical workflow using synthetic data only.
6. **Laboratory** — create a demo test and show pending-test status.
7. **Pharmacy/Inventory** — demonstrate stock and low-stock alerts.
8. **Billing** — show a sample invoice workflow.
9. **AI Assistant** — ask operational questions using synthetic/demo data.
10. **Security/Audit** — show role restrictions and audit events.
11. **Backup/Health** — show system health and backup readiness.
12. **Close** — explain pilot scope, UAT, security testing and deployment requirements.

Never use real patient data during a sales demonstration unless the hospital has formally authorized the environment and data handling.

# Hospital User Quick Start

1. Start the ERP client.
2. Sign in with your assigned account.
3. Use only the modules permitted by your role.
4. Search for a patient before creating a duplicate record.
5. Complete workflow fields accurately.
6. Sign out when leaving the workstation.
7. Report suspicious activity or errors to the hospital administrator.

Do not share passwords, export patient data unnecessarily, or install unapproved software on the ERP workstation.

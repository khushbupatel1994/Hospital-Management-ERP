# Commercial Release Checklist

- [ ] Production PostgreSQL configured
- [ ] Redis configured if required
- [ ] TLS certificate installed
- [ ] Secrets stored outside source control
- [ ] Backup completed
- [ ] Restore drill passed
- [ ] UAT signed off
- [ ] Independent security testing completed
- [ ] Critical/high findings remediated and retested
- [ ] Privacy/legal review completed
- [ ] Monitoring configured
- [ ] Signed Windows installer produced
- [ ] Customer documentation delivered
- [ ] Support/SLA agreement approved
- [ ] Pilot rollback plan verified

CLOUD SECURE HOSPITAL ERP - HOSPITAL DEPLOYMENT

1. This package is for hospital staff/end users.
2. Do NOT install Python or developer packages.
3. Run INSTALL-HOSPITAL.bat, or start the EXE directly.
4. Keep the application folder and database location protected by Windows permissions.
5. Do not share administrator credentials.
6. The compiled EXE does not ship with the Python source tree.

Security note:
A client-side EXE can still be reverse engineered by a determined attacker. For strongest IP protection, keep proprietary AI/business logic on a secured server and expose only authenticated APIs.
